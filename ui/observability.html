    Reading these charts
    CPU and memory cover VoiceGen and its child processes, including native models and prompt expansion. CPU at 100% uses one core, so multiple cores can exceed 100%. Memory is summed resident memory; shared pages can be counted more than once.
    GPU utilization and GPU memory cover the whole Mac, including other apps. A job chart shows the GPU counters observed while that job ran, rather than exclusive usage by that job. Apple Silicon shares memory between CPU and GPU; do not add these memory figures together.
    Samples are taken every second during a job and every five seconds when idle. Longer windows show bucket averages; hover or focus a chart and use the arrow keys to see the bucket’s peak. Missing counters and times when the generator was off appear as gaps. Resource graphs stay in the project’s SQLite database for seven days; sparse model events stay for 90 days.
    Model activity measures explicit boundaries with a monotonic clock. Warm reuse creates no new load event. Python weights, native weights/session construction, native destruction, and backend process startup/shutdown are separate scopes. First-inference compilation is not a weight-load measurement. Successful means and maxima cover all matches, grouped by model and scope; dots show only the current page. Interrupted operations have an unknown duration, not restart downtime.
