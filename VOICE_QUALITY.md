# Character dialogue: defaults, evidence and practical workflow

These defaults prioritize reference identity and accent before additional acting. They are useful starting points for game dialogue, not a proven optimum for every speaker, accent or language. Generate complete lines, preserve raw takes, and judge exact words, identity, accent, emotional intent and pacing separately. More emotion can change the perceived speaker.

## Recommended defaults

Numbers below mean temperature / top-p / top-k unless stated otherwise. API overrides remain explicit; admitted queue jobs retain their original frozen effective settings. The studio's **Apply recommended defaults** action resets model performance controls while keeping dialogue, voice/reference, character description, seed and output folder. Previously saved forms retain their settings until that action is chosen.

| Backend | Default | Conditioning and purpose |
|---|---|---|
| `voxcpm2` | `clone_mode: auto`, 10 steps, CFG 2 | With a reference, exact transcript and no new emotion/accent directions, admission resolves auto to combined identity + recorded performance. Otherwise it resolves to reference. Explicit reference/combined/continuation remain available. |
| `qwen3` | Temperature .9; checkpoint/native top-p 1 and top-k 50 | Base uses full ICL with a transcribed recording and active audio encoder; installed MLX raises the ICL repetition penalty to at least 1.5. Without transcript it uses speaker-vector conditioning. VoiceDesign creates a new identity; CustomVoice uses supported preset speakers. |
| `chatterbox` | Exaggeration .3, CFG .5, temperature .8 | Conservative **provisional** Original-model character default. Upstream neutral .5/.5 remains selectable. Lower CFG .3 is a separate pacing experiment; stronger exaggeration is opt-in. |
| `indextts` | Follow recording, duration factor 1, temperature .8, internal segment gap 400 ms | Preserve the original speaker anchor; no forced emotion vector or emotion audio. Segment gaps are not a guarantee about every sentence boundary. |
| `fish` | .7 / .7 / 30, no delivery tags | Exact reference transcript and a recording with the desired accent. Short structured tags and supported local bracket tags are optional. |
| `higgs` | .8 / .8 / 30, no emotion/prosody/style tags; UI audio limit 2,000 | Exact reference transcript. Keep the baseline identity before experimenting with one official control; do not stack strong global acting by default. |
| `moss` | Audio sampler 1.5 / .6 / 50, repetition penalty 1.1 | VoiceGenerator designs from an audible description in English or Chinese. A description and repeated seed do not lock the speaker across different lines. |

For Vox `auto`, requested metadata retains `auto`; effective metadata and the durable queue freeze the concrete mode before execution. Existing queued reference jobs are not upgraded. Historical omitted-mode keyed retries recover their old jobs through narrowly versioned compatibility checks. New auto requests and explicit reference requests have distinct fingerprints. Other backends resolve auto to reference without acquiring Vox conditioning capabilities.

In the UI and API, Auto follows the recording when new emotion/accent directions are empty. The fields remain editable: entering new directions resolves Auto to flexible reference conditioning. Combined and Continue performance disable those fields, with a lighter grey background and an explanation. No private voice or character preset is shipped.

Higgs exposes searchable Emotion, Prosody and Style inputs in the delivery section. Pick a catalog option, or type a custom direction and use Suggest control with the local LLM, then review and apply the recognized option. Suggestions target one category and preserve the others; unmatched directions can return no suggestion. Unknown tags are never inserted into speech. Its reference recording supplies the accent cue; it has no free-text accent control here, and the accent can still drift. Keep an exact saved transcript and compare the default Follow recording settings with one acting control at a time. A UI or transcript fix alone does not establish improved accent fidelity.

Higgs can also hit its audio budget without generating EOC, its end marker. The pinned runtime defaults to 2,048 tokens; this service keeps its existing 2,000-token maximum and uses 2,000 for new UI settings. API requests retain the 1,000-token default; explicitly send `max_tokens:2000` for the recommended larger budget. Higher limits allow a longer take rather than improving quality, and do not guarantee EOC. The default native text chunk size remains 1,024 characters to preserve existing short-line delivery. `higgs.text_chunk_size` can be reduced for longer passages, with possible changes in pacing and how acting tags apply across chunks. Incomplete output remains a failure; successful sibling options stay available.

## Why these choices

**VoxCPM2.** The [official Ultimate Cloning application](https://github.com/OpenBMB/VoxCPM/blob/main/app.py) combines a reference with transcribed performance context. Style instructions are unsupported in that path, as discussed in [upstream issue 210](https://github.com/OpenBMB/VoxCPM/issues/210). The installed adapter supplies all three native inputs (`ref_audio`, `prompt_audio`, `prompt_text`) using the same recording. Neither higher CFG nor an unused temperature slider is a universal expression fix. Combined mode preserves the whole line and counts the reference transcript toward its token budget.

**Qwen.** A historical MLX accent problem was repaired by loading the missing tokenizer encoder configuration: [issue 439](https://github.com/Blaizzy/mlx-audio/issues/439), [repair 461](https://github.com/Blaizzy/mlx-audio/pull/461). This is an implementation defect to audit, not a reason to lower temperature indiscriminately. The [independent ICL versus speaker-vector comparison](https://arxiv.org/html/2610.23678v1) found reference domain and conditioning matter, with tradeoffs rather than an ICL win on every measure; its human evaluation was limited and did not test Romanian English. The [official Qwen project](https://github.com/QwenLM/Qwen3-TTS) distinguishes Base, VoiceDesign and CustomVoice. Base has no free-text acting-instruction path. An explicit empty `ref_text` can diagnose vector-only conditioning; exact transcribed character references normally use ICL.

**Chatterbox Original.** A Mac user's [117-variant comparison](https://www.pardel.dev/2026/10/04/cloning-your-voice-on-your-own-machine) found lower exaggeration .3 useful for their voice. This is one speaker with mostly single runs, not an accent benchmark; it supports a provisional conservative default. The [official guidance](https://github.com/resemble-ai/chatterbox) uses neutral .5/.5 and suggests lower CFG for deliberate pacing. Original uses the first six seconds for speech-token conditioning, first ten for decoder conditioning and the full waveform for voice embedding. Turbo tags and multilingual transfer advice are different capabilities. No automatic reference normalization is introduced.

**IndexTTS.** [Official controls](https://github.com/index-tts/index-tts) separate speaker identity from emotion audio/vector and duration. [Community emotion-reference discussion](https://github.com/index-tts/index-tts/issues/392) concerns an earlier model and does not establish a universal emotion mixture for 2.5. A [third-party 15-test duration study](https://indextts.app/index-tts-2-5-review) supports functional duration changes but leaves naturalness and identity to listeners. Keep follow-recording as default; separately try same-speaker emotion audio at alpha .3–.5 or duration 1.1. Do not change both in a first comparison.

**Fish.** A [temperature sweep](https://github.com/fishaudio/fish-speech/issues/1280) reported that raising .6–1.5 mostly increased variation when tags and neutral text disagreed. Reports of weak tagged clones coexist with successful cloning; none establish a better universal sampler. The historical [MLX sampler discrepancy](https://github.com/Blaizzy/mlx-audio/issues/571) was [repaired](https://github.com/Blaizzy/mlx-audio/pull/573). Exact transcript conditioning and narrow, visible tags are more defensible than increasing randomness. Repetition penalty is unused here and speed would be postprocessing, so neither is exposed.

**Higgs.** The [pinned native documentation](https://github.com/0xShug0/audio.cpp/blob/082177ecac45f1965929ded33cd81a85c13542f1/docs/models/higgs_audio_tts.md) specifically favors top-k 30 over 50 to reduce premature end-of-content. A [same-seed community tag/no-tag comparison](https://huggingface.co/bosonai/higgs-tts-3-4b/discussions/20) reports identity changes with emotional tags; it used another language/runtime and is not proof every tag fails. Keep the untagged baseline, then try a single control from the [official catalog](https://huggingface.co/bosonai/higgs-tts-3-4b/blob/239f63fb7b02b1aa085f98d9efae5e35cc5523e8/PROMPTING.md). No invented accent tokens, automatic sound effects or millisecond promises. Incomplete generation remains an error; native repetition penalty is unused.

**MOSS.** The [official VoiceGenerator card](https://huggingface.co/OpenMOSS-Team/MOSS-VoiceGenerator) and [pinned native report](https://github.com/0xShug0/audio.cpp/blob/082177ecac45f1965929ded33cd81a85c13542f1/docs/models/moss_voicegen.md) support its specialized audio sampler. The native author documents speaker changes when text changes despite a fixed seed. No convincing independent controlled result justifies replacing 1.5 with 1.2 globally. Describe audible age, register, accent and delivery concisely; avoid biography or contradictory directions. If a design is liked, save its output and clone that audio with a compatible backend for later identity reuse. Other MOSS-family models' cloning/language features do not belong to VoiceGenerator.

## Reference, acting and pacing recipes

1. Choose an authorized recording containing the desired speaker, accent and natural performance. End at a complete word and transcribe exactly that crop. Keep the original media. A longer clip is an experiment, not a universal improvement; avoid blanket denoising, loudness normalization or silence trimming that could change conditioning cues.
2. Generate a full dialogue line with unchanged words, a fixed seed and the model's default sampler. Save the raw WAV and provenance before adding acting. Stock language selectors are not accent selectors.
3. Change one factor: one Fish cue, one Higgs catalog directive, modest Index emotion transfer, or a Chatterbox candidate. Review the rendered text; never paste delivery tags into the reference transcript. Keep the original speaker anchor during emotion transfer. If acting weakens identity or accent, retain the baseline.
4. For longer pauses, use **Adjust pauses** on an existing take. Review the audio and select quiet spans explicitly. The default target is 750 ms **total** gap: add only missing silence, preserve longer gaps and every original speech sample, retain the raw source. No automatic sentence alignment or guarantee that every sentence gap was verified is claimed. Native pause tokens and Index internal segment gaps do not specify exact sentence milliseconds.

## Runtime verification and limits

The installed deployment was audited with MLX Audio 0.6.1, MLX 0.32.4 and pinned audio.cpp `082177ecac45f1965929ded33cd81a85c13542f1`. The Qwen loader parses/passes `encoder_config`; Base, VoiceDesign and CustomVoice tokenizer configurations contain it, with 225 encoder tensors among 496 tokenizer tensors each. Historical encoder and worker-RNG repairs are already present; no upgrade or download was needed. Reference-based ICL now fails visibly if its encoder is unavailable rather than silently claiming ICL.

Fish's quantized loader remains strict and converts working reference audio to its 44.1 kHz interface. Stored working references are 16 kHz mono; upsampling cannot restore discarded bandwidth. Native Higgs builds the codec's required inputs. Preserve a successful reference path while comparing controls; compare original-media fidelity separately if needed. Native token counts and separated native load time are unavailable and remain unset; process totals include startup/loading. Raw decoding checks cannot establish accent, word accuracy or acting quality.

Evidence is strongest for runtime mechanics, conditional controls and known failure modes. Independent listening studies are small, use different hardware/precision/languages, and often report only one speaker. No Romanian-accent optimum or hosted-service parity is established. Respect each backend's [license and output restrictions](BACKENDS.md); no training, new weights or paid cloud generation is part of this workflow.

New compatible Fish/Index/Chatterbox/Qwen requests offer configurable punctuation pacing (500 ms extra after sentences, 200 ms after commas), using separate phrase synthesis with the same reference/fixed speaker. This changes performance context: compare accent and flow against whole-line delivery. Disable it under Advanced settings or `<model-id>.punctuation_pauses:false` when continuity is preferable. MOSS stays single-pass and receives approximate timing instructions; it has no enforced millisecond pause control. See API.md for the actual controls and limits. This is not forced alignment or an automatic edit of a full-line take.
